# Slipstream 1.5.0

- **Pause von außen:** Ein anderes Programm auf dem Mac kann Slipstream jetzt anhalten, zum
  Beispiel solange ein Laptop im Akkubetrieb ist oder jemand daran arbeitet. Die Einstellung ist
  aus, bis sie jemand einschaltet; ohne sie arbeitet Slipstream wie bisher. Sie müssen nichts tun.
